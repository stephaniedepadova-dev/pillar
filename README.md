# Pillar — Talent Acquisition proposal

A standalone, bilingual (English / Italian) candidate microsite by Stephanie De Padova.

## Project principles
- Independent repository: `stephaniedepadova-dev/pillar`
- Does not modify or depend on the personal portfolio repository.
- Clearly identified as an independent candidate proposal, not an official Pillar website.
- Responsive layout, vanilla HTML/CSS/JS, no build step.

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose branch **main** and folder **/(root)**.
4. Save and wait for GitHub Pages to publish.

Expected URL: https://stephaniedepadova-dev.github.io/pillar/

## Before sharing
- Confirm the public contact email in `index.html`.
- Review all candidate metrics and wording.
- Verify any company-specific references and live vacancies before adding them.
- The current page intentionally avoids unverified claims about Pillar's current team size, funding, customers or open roles.
